## AMNC4Pi
Pi utilites:
1) cpuFlash - flash the cpu from the pi
2) eeprom - program the HAT eeprom
3) fpagflash - utility to update the FPGA (Runs on Linux and windows)
4) IP400spi - utility to send IP400 frames over UDP to the SPI port
5) stm32flash - flash utility for CPU only.
